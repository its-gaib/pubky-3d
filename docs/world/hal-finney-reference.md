# Hal Finney runner reference

The decorative `@halfin` runner uses an individually modeled, stylized young-adult likeness. The reference is Hal's broad forehead, fuller cheek line and jaw, prominent nose bridge, rounded nose tip, and dark side-parted wavy hair. The eyes and closed mouth have a calm, focused expression. No age lines, grey hair, or exaggerated scowl were added.

References viewed while modeling:

- [Hal Finney doing math, 1972](https://commons.wikimedia.org/wiki/File:Hal_Finney_doing_math.jpg), Daily News-Post staff photograph, May 12, 1972. This provides a clear side profile and early hair shape. Wikimedia Commons labels the photograph public domain in the United States.
- [Member Profile: Hal Finney, Cryonics, second quarter 2019](https://www.cryonicsarchive.org/docs/cryonics-magazine-2019-02.pdf), Nicole Weinstock, Alcor Life Extension Foundation. The family-supported profile includes young-adult photographs, especially Hal with Fran beside a computer and the late-1970s “How to Study” photograph. These informed the adult proportions and wavy hair rather than reproducing the teenage portrait literally.

The mesh is a hand-modeled interpretation, not a scan or a photorealistic reconstruction. Photographs are reference material only: the runner bundles no reference bitmap and makes no request for a Hal portrait. It uses no face-recognition model or identity inference. The runner retains its athletic kit, articulated animation, track, and clickable `@halfin` mention.
